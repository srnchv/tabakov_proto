# Театр Олега Табакова — UX клик-прототип сайта

Прототип студии Charmer к предложению по разработке сайта театра (сентябрь 2026).
Серый вайрфрейм: показывает структуру, навигацию и логику, а не финальный дизайн. Все данные тестовые, имена артистов и составы условные.

## Что внутри

Статический SPA без сборки: `index.html` + `style.css` + `app.js` (hash-роутинг, Inter).

- **Главная** — заставка при первом заходе (пропускается кликом), ближайшие спектакли, премьера, новости
- **Афиша** — фильтры по месяцу, сцене и жанру; составы на дату; статусы «мало мест» и «продано»
- **Покупка билетов** — единая модалка шести билетных операторов (Мосбилет, Intickets, Ticketland, Яндекс Афиша, Kassir.ru, МТС Live) с deep-link-переходами и статусами наличия
- **Репертуар** — текущий и архив, фильтр по сценам
- **Страница спектакля** — девять блоков по ТЗ: афиша-фото, описание, атрибуты, даты с составами и билетами, артисты по ролям (двойные составы), постановочная группа, фотогалерея с лайтбоксом, собственный видеоплеер, отзывы (текст и видео, с модерацией), СМИ
- **Артисты** — каталог (ч/б → цвет при наведении) и персональная страница: роли, ближайшие выходы на сцену из афиши
- **О театре** — 10 подразделов: история, здания, хронограф, архив спектаклей, гастроли, награды, премия Табакова, создатели, сотрудники, документы
- **Пресс-центр** — новости театра и публикации СМИ, пресс-кит
- **Контакты** — обе сцены
- **Поиск** — по спектаклям, артистам и новостям
- **Версия для слабовидящих** — переключается в шапке: без изображений, усиленный контраст, крупный шрифт

Ключевой принцип, который доказывает прототип: сущность создаётся один раз и выводится везде через связи. Артист заведён единожды — и появляется в спектакле, в составе на дату в афише и на собственной странице с «ближайшими выходами».

## Запуск

Открыть `index.html` или любой статический сервер:

```bash
python3 -m http.server 5050
```
