# Театр Олега Табакова — кликабельный UX-прототип

[Открыть прототип](https://srnchv.github.io/tabakov_proto/)

Нейтральный прототип для согласования структуры и сценариев по ТЗ от 9 сентября 2026 года.

- Главная: листалка восьми спектаклей, люди театра, новости.
- Афиша: месяц, неделя и список; фильтры; карточка поверх календаря по нажатию на дату. Несколько показов одного дня перелистываются внутри карточки.
- Репертуар: поиск, фильтры и архив; подробные страницы спектаклей.
- Артисты и постановочная группа: поиск, алфавит и персональные страницы.
- Пресс-центр, контакты, документы, поиск по сайту и настройки доступности.

Данные и прямые билетные ссылки — снимок на 16 сентября 2026 года. Наличие билетов подтверждается у оператора. Формы демонстрируют валидацию и не отправляют персональные данные. CMS, рассылка, полный перенос архива и производственные интеграции не подключены. Подробная карта готовности доступна в разделе «Соответствие ТЗ».

## Файлы и запуск

Статический сайт без сборки: `index.html`, `app.js`, `public-data.js`, `concept.js` и таблицы стилей. `wireframe.css` задаёт нейтральный вид; предыдущие имена файлов сохранены для совместимости. Материалы фотогалерей находятся в `assets/`.

Откройте `index.html` либо запустите из папки репозитория:

```sh
python3 -m http.server 8767
```

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.
